# History

Choose a vehicle, range and metric to view its route and telemetry chart. The API bounds
the result and downsamples to the requested maximum so a browser does not receive an
unbounded month of raw samples. Exact source count and latest selected value remain
visible beside the route and chart. The initial metric follows the vehicle and available
telemetry—battery for an EV, fuel or engine data for a combustion vehicle, and a useful
available signal for a hybrid—while every canonical metric remains selectable.
